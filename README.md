# 桌面待办

workTodo 是 Windows 可折叠悬浮待办面板。第一版采用 C# / .NET 10、WPF 和 SQLite，单机离线使用。

## 运行

从 [GitHub Releases](https://github.com/nipaiyi/workTodo/releases) 下载 Windows x64 便携包，解压后运行 `DeskTodo/DeskTodo.exe`。运行包自带 .NET，不需要另装运行时，支持 Windows 10/11 x64。

源码仓库不包含运行包、SDK 缓存或个人待办数据。从源码构建后，可双击根目录的 `Start.cmd`，或运行 `dist/DeskTodo/DeskTodo.exe`。移动运行包时需要携带整个 `DeskTodo` 文件夹。

- 顶部向下箭头收起为小挂件，点击挂件展开；拖动标题区域或挂件可以移动位置。
- 输入任务名称按 Enter 或点击加号：“今日”视图添加到今天，“未来”视图添加到明天；铅笔按钮可以选择日期并填写备注。
- 勾选完成；任务右侧菜单可以编辑、改期或移入回收站。
- 底部撤销按钮撤销最近一次任务操作，也可在非文本输入区域按 Ctrl+Z。
- “今日”包括当天安排和以前未完成事项；“未来”显示未来未完成事项；“记录”按实际完成日期查询；“回收站”可以恢复删除的任务。
- 图钉切换置顶，齿轮打开设置；底部减号隐藏到托盘。右键挂件或点击托盘图标可以找回窗口。
- 设置支持全屏隐藏、开机启动、导出备份和恢复备份。选择开机启动前，先把发布目录放在固定位置。
- Alt+F4 只隐藏面板；彻底退出请使用设置或托盘菜单里的“退出”。

## 数据

默认数据位置：`%LOCALAPPDATA%/DeskTodo/tasks.sqlite`。数据与程序分开存放，更新发布目录不会覆盖任务。

任务修改成功后立即写入数据库；自动备份在启动、退出及运行期间每 5 分钟更新，日常备份保留最近 14 个日期。备份位于同一数据目录下的 `backups`，不会防止整块磁盘损坏，可另外导出到其他位置。

恢复备份会先保留一份 `before-restore-*.sqlite`，然后替换任务，保留当前窗口设置。恢复前验证文件完整性和应用版本；验证失败时当前任务保持原样。原始错误日志位于数据目录的 `errors.log`。

指定独立数据目录：

```powershell
.\dist\DeskTodo\DeskTodo.exe --data-dir ".\my-data"
```

跨天保留原任务和原计划日期，不复制、不自动改期。完成记录以本地时区下的实际完成日期为准，撤销完成后该记录退出已完成视图。

清空本地测试数据：先从托盘或设置中退出应用，再打开 `%LOCALAPPDATA%/DeskTodo`，删除 `tasks.sqlite` 及 `backups` 文件夹。若存在 `tasks.sqlite-wal`、`tasks.sqlite-shm` 或 `tasks.sqlite-journal`，也一起删除。此操作会同时重置面板位置和设置；下次启动自动建立空数据库。仅在窗口里删除任务会保留回收站和旧备份。

## 开发

源码：`src/DeskTodo` 为 WPF 应用，`src/DeskTodo.Core` 为任务规则和数据库；`tests/DeskTodo.Tests` 为可执行的数据验证项目。

工作区已清理本地 SDK、NuGet 缓存、重复构建输出及测试产物，保留源码和便携运行包。日常运行不需要这些开发文件。继续开发时先运行以下脚本，重新准备的官方 SDK 和 NuGet 缓存仍放在 `.tools` 中：

```powershell
.\scripts\setup.ps1
.\scripts\build.ps1 -Publish -Verify
```

`build.ps1` 默认构建并运行数据验证；`-Publish` 生成便携目录；`-Verify` 自动操作应用自己的 WPF 控件并在 `artifacts` 下输出截图与检查结果。测试使用独立数据库，不修改正式数据。依赖已还原时可使用 `-SkipRestore`。
